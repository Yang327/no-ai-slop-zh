# No AI Slop 中文自查评测清单

改写完成后，请对照以下自检项逐条核对（答“通过”或“不通过”）。若有任意一项未通过，必须修改正文后再行交付。
若为“仅诊断模式”，确保按清单逐条列出具体病句证据与改法，严禁重写正文或打分。

## 1. 核心原则核查

1. 是否保留了原作者的观点，没有擅自捏造数据、案例或观点？
2. 是否保留了原作者独特的口吻、俚语、幽默感、自嘲或粗粝感？
3. 是否做到了“最小有效修改”，没把原本写得生动好玩的真人句子改掉？
4. 是否删除了假大空的背景铺垫，但保留了作者亲身经历的故事或真实情绪？
5. 每一句存留下来的话，是否都经受住了“可移植性检验”（非任何竞品都能套用的空话）？
6. 动词是否精准有力，是否消灭了无主语的虚词套话？

## 2. 违禁词与黑话核查

1. 是否彻底消灭了“赋能、抓手、闭环、底层逻辑、链路、颗粒度”等大厂黑话？
2. 是否彻底清除了“深刻领会、多措并举、谱写新篇章、划时代意义”等公文官腔？
3. 是否去除了“毋庸置疑、显而易见、相得益彰、方兴未艾”等成语批发与空洞副词？

## 3. 核心病灶核查

1. **废话开头**：是否彻底删除了“在当今快节奏的时代/随着AI的发展/今天我们来聊聊”等清嗓子废话？
2. **假大空升华（重中之重）**：是否坚决删除了文末强行上价值、时代号召、人生感悟的鸡汤尾巴？
3. **爹味说教**：是否删除了“我们需要清醒地认识到/大家必须明白”等好为人师的居高临下语气？
4. **二元与排比**：是否清除了“不是X而是Y”、“不仅是X更是Y”等刻意对仗的机器句式？
5. **欧化翻译腔**：是否消灭了“进行了……”等弱动词，并删掉了 80% 泛滥累赘的“的”？
6. **标点与格式**：是否去除了多余的双破折号（——）、无意义的冒号列表以及标题 Emoji？

## 4. 终审朗读测试

1. 把修改后的文字大声读出来，是否像一个真诚、专业、有锋芒的真人在自然交谈？
2. 是否包含完整的修改后正文与简明扼要的 **【修改说明】**？
